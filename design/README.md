# «Знакомый редактор» — комплект дизайна

Выбранный второй вариант от 19 октября 2026 года. Здесь сохранены все состояния показанного макета, а не только главный экран.

## Интерактивный макет

Откройте [familiar-editor.html](familiar-editor.html) в браузере двойным щелчком. Файл работает без сети и установки зависимостей.

Можно выбирать главы, переключать «Текст», «План сцен» и «Хронология», открывать «Материалы», выбирать «Персонажи», «Мир» и «Заметки», включать и выключать «Только текст».

Это макет навигации и внешнего вида. Он не редактирует и не сохраняет рукописи; оформление над текстом показано как образец панели. Окна создания книги, импорта, экспорта, поиска, настроек и восстановления ещё не нарисованы.

## Исходник

[familiar-editor.fragment.html](familiar-editor.fragment.html) — редактируемый исходник выбранного макета. Самостоятельный файл familiar-editor.html содержит и оформление, и сценарии переключений.

Удалённый прототип приложения не восстанавливался; комплект содержит только дизайн с вымышленным текстом.
