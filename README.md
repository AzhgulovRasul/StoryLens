# StoryLens

Локальный редактор рукописи для Windows: главы, привычное оформление текста, заметки, персонажи и мир, план сцен и простая хронология. Без аккаунта, синхронизации и встроенной модели.

[English](README.en.md) · [Скачать Windows-версию](https://github.com/AzhgulovRasul/StoryLens/releases) · [Результаты проверок](QA_RESULTS.md)

**0.1.0 — первый предварительный выпуск.** Основные сценарии проверены на компьютере разработчика; чистая Windows и длительная работа с реальными рукописями пока не подтверждены.

## Запуск

1. Скачайте `StoryLens-0.1.0-windows-x64.zip` со страницы выпуска и распакуйте целиком в доступную для записи папку. Node.js и Rust пользователю не нужны.
2. Запустите `StoryLens.exe`. Писать и сохранять книги можно сразу, без сети.
3. Для импорта и экспорта один раз запустите **`Prepare-converters.cmd`** при подключённом интернете. Скрипт получает Pandoc 3.12.1 и Typst 0.15.1 из их официальных GitHub-выпусков, проверяет SHA-256 и помещает в `tools`. Он не отправляет рукописи и не требует прав администратора. Скрипт и адреса открыты в `scripts/get-tools.ps1`.
4. После подготовки все пять форматов работают без сети. При переносе приложения копируйте всю папку `StoryLens`, включая `tools`.

Конвертеры не включены в публичный ZIP; их получает сам пользователь непосредственно у разработчиков. Комплект содержит MIT-лицензию StoryLens и уведомления о зависимостях. SHA-256 архива приведён в `SHA256SUMS.txt` рядом со скачиванием; контрольная сумма не заменяет цифровую подпись.

Требуется Windows 10/11 x64 с Microsoft Edge WebView2 Runtime. На этом компьютере запуск проверен. Чистая Windows и установка отсутствующего WebView2 не проверены. Программа не подписана цифровым сертификатом.

## Начало работы

1. Нажмите «Создать книгу», введите название и выберите родительскую папку. Приложение создаст в ней новую папку книги. Для открытия существующей книги выбирайте её папку с `project.json`.
2. Пишите в главе, используйте оформление сверху. Новая глава добавляется слева. Название главы меняется прямо над текстом. «Действия с главой» позволяют изменить порядок и удалить главу с подтверждением.
3. «Материалы» открывают персонажей, мир, заметки и файлы. Карточки допускают свободный текст. Добавленные файлы копируются в книгу. Щелчок по файлу позволяет сохранить его копию вне проекта.
4. «План сцен» и «Хронология» содержат отдельные записи. Стрелки задают порядок. Время события — произвольная подпись; автоматической сортировки дат нет. Сцену можно отнести к главе или оставить замыслом.
5. Поиск (`Ctrl+F`) ищет текст глав, названия и описания карточек, сцены и события. Содержимое вложенных файлов не индексируется. `Esc` закрывает поиск или режим «Только текст».
6. «Книга» открывает импорт DOCX, экспорт и резервные копии. Экспортируется вся рукопись по порядку глав. Карточки и вложения входят в полную копию проекта, а не в чистовой экспорт.

`Ctrl+S` — немедленное сохранение. `Ctrl+Z` / `Ctrl+Y` — отмена и повтор в редакторе; история текста сохраняется при переключении глав в текущем сеансе. Удаление главы, карточки, сцены или события подтверждается отдельно и не входит в отмену текста.

Кнопка **« »** на панели оформления обрамляет выделенный текст русскими кавычками, сохраняя его оформление. Без выделения вставляет пару `«»` с курсором внутри. Вставка кавычек отменяется одним действием.

## Сохранение и восстановление

Автосохранение начинается через 650 мс после последней правки. Статус «Сохранено» появляется после подтверждения записи Rust-ядром. При штатном закрытии программа дожидается сохранения; при ошибке предлагает вернуться. При принудительном завершении ещё не сохранённые последние правки могут потеряться.

В рабочей папке хранятся `project.json`, предыдущая исправная запись `project.previous.json` и `assets/`. Источник истины — структурированный JSON. Не редактируйте эти файлы вручную при открытой книге. Параллельный запуск той же книги блокируется; внешняя правка JSON останавливает запись.

Полные автоматические ZIP-копии создаются при первом сохранении после открытия и затем при сохранении не чаще одного раза в пять минут. Они лежат **рядом с папкой книги** в `StoryLens backups/<идентификатор книги>/`. Лимита количества пока нет: следите за местом и удаляйте ненужные старые копии через Проводник. Это защита от повреждения проекта, а не от поломки того же диска.

В «Книга → Резервные копии» можно сохранить текущую работу отдельным ZIP на другом диске, даже если обычное сохранение выдаёт ошибку. «Восстановить ZIP» проверяет структуру, пути и контрольные суммы вложений и создаёт новую папку. «Предыдущая запись» берёт `project.previous.json` и материалы из выбранной папки. На стартовом экране также доступно восстановление ZIP. Существующая папка не перезаписывается.

Если `project.json` повреждён: запустите приложение заново и восстановите ZIP либо нажмите «Из предыдущей записи» на стартовом экране и выберите повреждённую папку. Исходная папка останется нетронутой.

## Форматы и ограничения

Импорт DOCX создаёт **новую главу**, сохраняет исходный файл в материалах и показывает отчёт. Поддерживаются обычный текст, заголовки до третьего уровня, списки, цитаты, жирное, курсив, подчёркивание и зачёркивание. Оформление страниц, стили Word, встроенные изображения, таблицы как таблицы, комментарии и редактируемые сноски не поддерживаются. Таблицы разворачиваются в текст; сноски — в обычные записи. Импорт не заменяет проверку результата по исходнику.

Экспорт DOCX, PDF, EPUB, Markdown и TXT выполняется локально, без конвертации через сервис. В TXT нет оформления; Markdown не сохраняет все визуальные свойства. PDF использует установленный Times New Roman. Для PDF/EPUB/DOCX не заявляется точное воспроизведение вида редактора или исходного Word. Перед публикацией проверяйте файл в целевой программе.

Лимиты версии: 64 МБ рабочего JSON, до 10 000 глав, 250 МБ на вложение, 1 ГБ вложений суммарно; DOCX импорта — до 100 МБ в архиве, до 4096 записей, 64 МБ на распакованный файл и 128 МБ суммарно. Конвертация ограничена двумя минутами, захват вывода — 64 МБ и диагностик — 1 МБ; превышение прерывает операцию. Крупные проекты проверены ограниченно; подробности — [QA_RESULTS.md](QA_RESULTS.md).

Модель, аккаунты, сеть, синхронизация, пользовательские версии, шифрование и плагины в приложение не включены.

## Разработка

Требуются Node.js 22+, Rust 1.89+ и Windows C++ Build Tools. Для получения инструментов при первой подготовке нужен интернет; обычный запуск его не требует.

```powershell
git clone https://github.com/AzhgulovRasul/StoryLens.git
Set-Location StoryLens
npm.cmd ci
./scripts/get-tools.ps1
npm.cmd run tauri -- dev
```

Проверки: `npm.cmd test`, `npm.cmd run test:ui` (нужен Edge), `cargo test --manifest-path src-tauri/Cargo.toml --locked`. Сборка переносимого комплекта: `./scripts/package.ps1`. Скрипт собирает уведомления из локально загруженных зависимостей (`npm.cmd run notices`), создаёт release EXE, ZIP и `SHA256SUMS.txt`. Конвертеры в публичный ZIP не копируются.

Rust-ядро: `src-tauri/src/model.rs`, `storage.rs`, `convert.rs`, `main.rs`. Интерфейс: `src/main.ts`, `style.css`; очередь записи: `save-queue.js`. Схема и выбранные технические решения — [ARCHITECTURE.md](ARCHITECTURE.md). Лицензии компонентов — [THIRD_PARTY.md](THIRD_PARTY.md).
