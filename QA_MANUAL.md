# Проверка StoryLens пользователем

Используйте отдельную папку и вымышленный текст. Не начинайте приёмку с единственного экземпляра важной рукописи. Все кнопки ниже относятся к новой версии 0.1.0.

| Проверка | Действия и ожидаемый результат |
| --- | --- |
| Запуск | Распаковать весь ZIP. Запустить `StoryLens.exe`. Видны создание, открытие и восстановление книги. Интернет и аккаунт не требуются. |
| Подготовка форматов | Один раз выполнить `Prepare-converters.cmd` при подключении к интернету. Дождаться сообщения Ready. Затем отключить сеть и проверить импорт/экспорт. При ошибке SHA-256 инструмент не должен устанавливаться. |
| Новая книга | «Создать книгу» → название → родительская папка. В ней появляется новая папка книги; открывается первая глава. |
| Письмо | Набрать русский абзац, выделить слово, нажать «Ж», «К», «Ч». Отменить и повторить через Ctrl+Z/Ctrl+Y. Вставить несколько абзацев из Word и сравнить текст. |
| Главы | Добавить вторую главу, написать текст, вернуться к первой. Текст и оформление сохранились. Через «Действия с главой» изменить порядок. |
| Материалы | Создать персонажа, карточку мира, заметку. Внести текст, переключить вкладки. Добавить файл. Изменить исходный файл в Проводнике; копия в книге остаётся прежней. |
| План | Добавить сцену с главой и сцену без главы. Изменить описание и порядок. Удаление требует подтверждения. |
| Хронология | Добавить события с подписями «День 1» и «Раньше». Поменять порядок вручную. Порядок глав и сцен не меняется. |
| Поиск | Ctrl+F → слово из другой главы, карточки или сцены. Результат открывает соответствующее место. |
| Только текст | Включить режим: вспомогательные панели скрыты, текст редактируется. Esc возвращает обычный экран. |
| Повторный запуск | Дождаться «Сохранено», закрыть приложение, снова открыть папку книги. Проверить текст, оформление, материалы и порядок. |
| Перенос | Закрыть книгу. Скопировать всю папку книги в другое место. Открыть копию; материалы доступны. |
| DOCX | Импортировать **копию** своего DOCX. Появляется новая глава и исходник во вкладке «Файлы». Прочитать отчёт и сравнить абзацы/списки/выделения; таблицы и изображения не ожидаются как редактируемые объекты. |
| Экспорт | По очереди сохранить DOCX, PDF, EPUB, Markdown, TXT вне папки книги. Открыть в целевых программах. Русский текст, порядок глав и базовое оформление соответствуют ожиданиям. |
| Полная копия | «Книга → Резервные копии → Создать копию» на другой носитель. «Восстановить ZIP» под новым именем. Сверить текст, карточки и файлы. |
| Повреждение | Только на тестовой копии: закрыть книгу, испортить `project.json`. Открытие должно показать ошибку. «Из предыдущей записи» на стартовом экране восстанавливает новую папку. |
| Два окна | Открыть одну тестовую книгу в двух экземплярах. Второй не должен начать редактирование. После завершения первого книга снова открывается. |
| Ошибка записи | Только на отдельном тестовом носителе или папке: сделать запись недоступной. Правка должна вызвать видимую ошибку, оставаться в редакторе и допускать резервную копию в другое доступное место. Возвратить доступ и сохранить повторно. |

Запишите результат `PASS / FAIL`, версию Windows, шаги и точный текст ошибки. Скриншоты делайте на вымышленном тексте. Не отправляйте личную рукопись, содержимое `assets/` и полные копии проекта для обычной диагностики.
